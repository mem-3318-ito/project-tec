# plan見直し参考

基本的に[plan.md](./plan.md)の内容をベースに以下内容も考慮し設計を見直す必要がある。(docs/old/のファイルは触れないでください。)

1. SLDSは2を利用する
2. 画面数が15ページあり、画面ごとにコンポーネントを複数準備する必要がある
3. 共通コンポーネントは指定があり以下のみになる予定
   1. ヘッダー
   2. グローバルナビケーション
   3. パンくずリスト
   4. 戻るボタン（ホームに戻る、[親画面名]に戻る、戻る、キャンセル）
4. コンポーネントの区切りで検索とテーブル(ページネーション付き)で別コンポーネントとして作る予定だが、検索するとテーブルの内容が変化するようなコンポーネントを跨ぐ処理が発生する場合もあるので、考慮する必要あり。
5. コード管理にBacklogのgit利用を想定しているのでCIを利用できないことも考慮する
6. Husky(pre-push)により、push前にlint等を実行し、PRレビューはUI/UXや表示、動作を中心にレビューできるように考慮する。
